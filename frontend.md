## Starten van de frontend
1. Als je niet in .../frontend zit voer deze commando uit -> cd frontend, als het goed is zit je nu in frontend map (Dit hoef je maar 1 keer uit te voeren)
2. Voer daarna deze commando uit: npm run dev, als dat is gelukt zou je dit moeten zien:

   <img width="541" height="129" alt="image" src="https://github.com/user-attachments/assets/40ff202f-8524-429a-9868-9d09433f2cc9" />
4. Klik op de link, als het goed is zie je nu de website.
